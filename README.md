This program lets you set up the master and slave radios using the OmniRig application. 
You select your radio brand for Rig1 and Rig2 and set the serial information. 
In this state, it reads the master and slave frequencies for the first time, and by pressing the Sync button, 
it sets the slave frequency to match the master so you can monitor it. That's how this app is used.
The radios that can be set in OmniRig are automatically detected, and their model and frequency are displayed.
